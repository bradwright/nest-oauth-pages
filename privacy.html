Privacy policy

This policy covers the owner’s personal Home Assistant Nest integration and this informational website.

Data accessed

With the owner’s permission, the integration accesses selected Nest devices’ identifiers, names, settings, temperature setpoints, temperature, humidity and heating activity. Google may also provide home names, room names and postal code metadata when home information access is authorised.

OAuth credentials and Google Cloud project, topic and subscription identifiers support authentication and device-event delivery.

How data is used

Data is used to display and control the selected devices in the owner’s private Home Assistant installation, record configured device history and run household automations. Pub/Sub access is used to receive Nest device updates through the configured event topic and subscription.

The integration does not sell Google user data, use it for advertising or use it to train artificial intelligence models. Its use of Google data follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and access

Credentials and connected-device data are stored in the owner’s Home Assistant installation and its configured history and backups. Any local credential backup is kept in an untracked, access-restricted environment file. Access is limited by the owner’s Home Assistant, host and backup access controls. Retention follows the owner’s configured history and backup policies.

Services involved

Google processes Nest API requests, authorisation and Pub/Sub device events. Home Assistant receives and uses that data for the purposes described above. The public GitHub Pages website does not receive the integration’s credentials or device data.

The website uses no analytics scripts, advertising or application cookies. Its hosting provider may process ordinary request information, such as IP addresses, under the GitHub privacy statement.

Revocation and deletion

The owner can revoke the integration’s Google account permissions at Google Account connections, and remove the Nest integration and application credentials from Home Assistant. Revocation stops future access. Existing recorded history, local credential backups and Home Assistant backups can be deleted separately through the owner’s local administration tools.

Contact and changes

Questions can be directed to the owner using the support contact shown on Google’s consent screen or the maintainer’s public GitHub profile. Changes to data practices will be reflected in this policy and its update date.
